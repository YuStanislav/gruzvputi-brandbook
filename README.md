# Груз в пути - материалы бренда

Откройте [галерею](index.html) для просмотра и скачивания. Для просмотра извлеченного архива подключение к интернету не требуется. Сохраняйте папку brand рядом с index.html.

В комплекте: логотипы SVG/PNG, маскот для двух тем, иконки устройств, шесть стикеров, цветовые токены, Manrope с SIL OFL, брендбук PDF и фирменные обложки. Публикацию набора Telegram выполняет владелец аккаунта.

Пять палитр: Фирменная, Океан, Тайга, Закат и Графит. Переключатель в шапке меняет весь брендбук и ссылки на соответствующие логотипы, иконки, баннеры, токены, PDF и отдельный ZIP. Общий архив содержит все готовые варианты без вложенных ZIP. Маскот и стикеры сохраняют исходный сине-белый образ.
