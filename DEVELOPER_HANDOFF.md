# Передача разработчику: движение и заказы

## Что посмотреть

- [Брендбук](https://yustanislav.github.io/gruzvputi-brandbook/).
- [Заказы и отклики](https://yustanislav.github.io/gruzvputi-brandbook/brand/10-motion/orders.html): интерактивный прототип по референсам пользователя, в стилистике «Груз в пути».
- [Калькулятор](https://yustanislav.github.io/gruzvputi-brandbook/brand/10-motion/truck.html#calculator-motion): адреса → маршрут → машина → пример цены.
- [Грузовик](https://yustanislav.github.io/gruzvputi-brandbook/brand/10-motion/truck.html): доработанное движение, фон и подвеска.

## Где исходники

| Часть | Файлы |
| --- | --- |
| Заказы и отклики | `brand/10-motion/orders.html`, `order.html`, `orders.css`, `orders-desktop.css`, `orders.js` |
| Сценарий калькулятора | `brand/10-motion/calculator.css`, `calculator.js`; разметка в `truck.html` |
| Анимация грузовика | `brand/10-motion/truck.html`, `truck.css`, `truck.js` |

| Поведение заказов и тайминги | `brand/10-motion/ORDERS.md` |
| Шрифт и изображения | `brand/06-fonts/`, `brand/01-mascot/`, `brand/02-logos/` |

Это обычные HTML/CSS/JavaScript без сборки и внешних библиотек. Для локального просмотра запустите из корня `python -m http.server 8765`, затем откройте `http://127.0.0.1:8765/`.

На ширине от 1000 px показывается список карточек, как в мобильном варианте. Нажатие — обычный переход на отдельную страницу `order.html?id=1` или `order.html?id=2`. На ней видны предложения и меню заказа; кнопка назад возвращает к списку. На меньшей ширине и в `?embed=1` сохраняется мобильное переключение внутри примера. `?view=mobile` позволяет посмотреть мобильный вариант на большом экране. Данные демо и тема сохраняются в sessionStorage текущей вкладки при переходах между страницами; «Начать заново» сбрасывает пример.

## Что переносить в продукт

### Уведомления

[Интерактивный пример](https://yustanislav.github.io/gruzvputi-brandbook/brand/10-motion/notifications.html), [мобильный предпросмотр](https://yustanislav.github.io/gruzvputi-brandbook/brand/10-motion/notifications-mobile.html). Исходники: `brand/10-motion/notifications.html`, `notifications.js`, `notifications.css`. Компонент также подключён в примерах заказов. Роли переключаются в отдельном примере.

Панель справа на десктопе и модальное окно на мобильном используют HTML dialog и не требуют разрешений браузера. Для клиента показаны новые и изменённые отклики; для перевозчика — новые подходящие заказы с основными параметрами. [Постановка и замечания по реальному API ветки target](brand/10-motion/NOTIFICATIONS.md) описывают прочтение по id, необходимые поля событий, роли, подбор заказов, переходы и состояния ошибок. Рабочий сайт в этой поставке не изменялся.

### Заказы

Список заказов → экран откликов → меню управления и демо-чат. Сохранять прочтение сообщения в счётчике заказа, отображать цену рядом с рейтингом, после отмены показывать отдельное состояние. Перенести адаптивность, клавиатурную навигацию, фокус диалогов, светлую/тёмную темы и `prefers-reduced-motion`.

Прототип использует вымышленные данные и память вкладки. Сервер, авторизация, реальные расчёты, отправка сообщений, выбор исполнителя и реальные операции с заказами не подключены. Для продукта заменить демонстрационные массивы и обработчики вызовами API, добавить загрузку, ошибки, проверки прав и подтверждения фактических действий.

Грузовик и калькулятор декоративные: они не показывают реальное положение машины или прогресс поиска перевозчика. Адреса и цены калькулятора условные.
