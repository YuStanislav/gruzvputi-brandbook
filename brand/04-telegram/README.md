# Стикеры «Груз в пути»

Шесть статичных стикеров 512 × 512 px с прозрачным фоном, белым контуром и подписью Manrope ExtraBold. Папки `png/` и `webp/` содержат одинаковый набор в двух форматах. Для загрузки достаточно одного формата. Файлы меньше 512 KiB.

## Публикация

1. Откройте официальный [@Stickers](https://t.me/stickers) в Telegram и создайте статичный набор.
2. Загрузите шесть PNG или WebP как файлы без сжатия, назначьте эмодзи из таблицы.
3. При необходимости используйте [обложку 100 × 100 px](pack-thumbnail.png).
4. Следуйте текущим подсказкам @Stickers, задайте свободное короткое имя и опубликуйте набор.

[manifest.json](manifest.json) содержит только сопоставление готовых файлов, подписей и эмодзи. [Лист просмотра на двух фонах](preview-light-dark.png) служит для проверки, а не для загрузки как стикер.

Требования: [Telegram static stickers](https://core.telegram.org/stickers#static-stickers-and-emoji). Шрифт: [SIL Open Font License 1.1](../06-fonts/OFL.txt).
