# Грузовик «Груз в пути»

Откройте [truck.html](truck.html): это самостоятельная демонстрация двух тем. В светлой версии — белый фургон с сине-белым хаски; в тёмной — фургон Navy с адаптированным маскотом. Кабина Electric Blue, контуры Navy / Sky, название — существующий векторный логотип с текстом в кривых. Шрифт интерфейса — включённый Manrope с кириллицей.

Маскот показан целиком на борту. Геометрия кузова, кабины, окна, ручки, фар и фонаря взята из указанного пользователем [грузовичка vinodjangid07 на Uiverse](https://uiverse.io/vinodjangid07/popular-owl-27). Сохранена подвеска с циклом 1 секунда и дорожное движение с циклом 1,4 секунды. Добавлены вращение колёс и фирменные полосы скорости.

## Файлы

- `truck.html` — демо и встраиваемый вариант.
- `truck.css` — изолированные классы `.gvp-truck*`, анимация и оформление демо.
- `truck.js` — пауза, режим iframe и синхронизация темы с родительской страницей.
- `wordmark-white.svg` — название из фирменного логотипа в кривых для синего борта.
- `preview-light-dark.png` — обзор двух тем; `preview-light.png`, `preview-dark.png`, `preview-mobile.png` — дополнительные статические превью.
- `LICENSE.uiverse.txt` — полный MIT notice автора исходного компонента.
- `source/` — сохранённый исходник Uiverse для сравнения; в публичную сборку не переносится.

PNG-превью показывают один кадр. Движение работает в HTML, без GIF, видео и сторонних библиотек.

## Подключение через iframe

Сохраните структуру папок `brand`: компонент использует соседние `01-mascot`, `02-logos`, `03-icons` и `06-fonts`.

```html
<iframe
  src="brand/10-motion/truck.html?embed=1&theme=light"
  title="Фирменный грузовик Груз в пути"
  loading="lazy"
  style="display:block;width:100%;height:410px;border:0"
></iframe>
```

`theme=dark` задаёт тёмную тему при открытии. В режиме `embed=1` остаются один грузовик и кнопка паузы. Для изменения темы без перезагрузки отправьте сообщение в уже загруженный iframe:

```js
frame.contentWindow.postMessage(
  { type: 'gvp-theme', theme: 'dark' },
  window.location.origin
);
```

Отправляйте сообщение также по событию `load` iframe, чтобы его начальная тема совпала с темой страницы. Обработчик принимает сообщения только от родительского окна и только два значения: `light` и `dark`. Состояние паузы при смене темы сохраняется.

Для прямого подключения разметки скопируйте один `<article class="gvp-truck">` из HTML и подключите CSS/JS; поправьте относительные адреса маскота, логотипа и шрифта при изменении расположения файлов. В CSS общая оболочка демо отделена комментарием от компонента.

## Поведение и доступность

Кнопка «Пауза» останавливает всю сцену, «Продолжить» возобновляет движение. При `prefers-reduced-motion: reduce` сцена автоматически становится статичной, а кнопка объясняет выбранный режим. Рисунок декоративный, скрыт от скринридера; название компонента и управление доступны с клавиатуры. Компонент не сообщает статус реального заказа и не обещает время доставки.

Проверено в Chromium: самостоятельная страница, встраивание при ширине 278, 320, 390 и 700 px, высота iframe 410 px, отсутствие горизонтальной прокрутки, пауза, синхронизация темы без сброса паузы, переключение системной настройки уменьшения движения и отсутствие ошибок загрузки локальных ресурсов.
