# Грузовик «Груз в пути»

Откройте [truck.html](truck.html): это самостоятельная демонстрация двух тем и пяти цветовых гамм. По умолчанию используется фирменная палитра: в светлой версии — белый фургон с сине-белым хаски; в тёмной — фургон Navy с адаптированным маскотом. Кабина Electric Blue, контуры Navy / Sky, название — существующий векторный логотип с текстом в кривых. Шрифт интерфейса — включённый Manrope с кириллицей.

Маскот показан целиком на борту. Геометрия кузова, кабины, окна, ручки и фар взята из указанного пользователем [грузовичка vinodjangid07 на Uiverse](https://uiverse.io/vinodjangid07/popular-owl-27). Сохранена подвеска с циклом 1 секунда и дорожное движение с циклом 1,4 секунды. Добавлены вращение колёс и фирменные полосы скорости. Прежние облако-полоска и фонарь заменены городским фоном: дальний силуэт движется медленнее, а местная достопримечательность проезжает за грузовиком. Один цикл достопримечательности — 24 секунды. Переход между циклами происходит за краем кадра, а при смене города достопримечательность сразу видна справа.

Выбор города общий для обеих тем. Доступны все 17 городов из списка: Москва, Санкт-Петербург, Саратов, Тюмень, Ижевск, Барнаул, Ульяновск, Иркутск, Ярославль, Томск, Оренбург, Кемерово, Рязань, Хабаровск, Киров, Пенза и Тула. Для каждого нарисована отдельная схематическая SVG-иллюстрация. Соответствия и официальные справочные источники — в [CITIES.md](CITIES.md).

## Файлы

- `truck.html` — демо и встраиваемый вариант.
- `truck.css` — изолированные классы `.gvp-truck*`, анимация и оформление демо.
- `palettes.css` — пять наборов цветовых переменных, подключается после `truck.css`.
- `truck.js` — выбор города и палитры, пауза, режим iframe и синхронизация с родительской страницей.
- `city-landmarks.js` — 17 оригинальных SVG-силуэтов; подключается до `truck.js`.
- `CITIES.md` — перечень достопримечательностей и справочные источники.
- `wordmark-white.svg` — название из фирменного логотипа в кривых для синего борта.
- `preview-light-dark.png` — обзор двух тем; `preview-light.png`, `preview-dark.png`, `preview-mobile.png` — дополнительные статические превью.
- [preview-cities.png](preview-cities.png) — все 17 городских силуэтов на одном листе.
- [preview-palettes.png](preview-palettes.png) — пять палитр в светлой и тёмной темах.
- `LICENSE.uiverse.txt` — полный MIT notice автора исходного компонента.
- `source/` — сохранённый исходник Uiverse для сравнения; в публичную сборку не переносится.

PNG-превью показывают один кадр. Движение работает в HTML, без GIF, видео и сторонних библиотек.

Сцена сохраняет пропорции грузовика и достопримечательностей при изменении ширины. Достопримечательности показаны в масштабе 110% исходных SVG и приглушены как часть дальнего плана: основание совпадает с горизонтом, а земля и вода перекрывают нижнюю часть зданий и мостовых опор. В широком встраиваемом варианте высота сцены ограничена 220 px, при ширине до 600 px — 160 px, чтобы вместить оба переключателя в iframe высотой 410 px. Фон, река, обочина и дорога продлены за пределы исходного `viewBox`. Дополнительные плитки городского силуэта и запас дорожной разметки заполняют боковые поля во всех фазах анимации. Начало и конец проезда достопримечательности вынесены за края даже максимально широкой карточки.

## Пять цветовых гамм

| Значение `palette` | Название | Цвет кабины | Характер |
| --- | --- | --- | --- |
| `brand` | Фирменная | `#0066FF` | Существующие синий, Navy и белый |
| `ocean` | Океан | `#00727C` | Глубокий бирюзовый и прохладный морской фон |
| `forest` | Тайга | `#286B48` | Хвойный зелёный и спокойный природный пейзаж |
| `sunset` | Закат | `#B84D22` | Медный акцент и тёплые сливовые оттенки фона |
| `graphite` | Графит | `#49556B` | Холодный сланцевый и нейтральный городской фон |

Каждый набор содержит отдельные светлые и тёмные цвета для грузовика, городского силуэта, достопримечательностей, воды и земли. Маскот сохраняет фирменные синий и белый, надпись на борту остаётся белой. Дно и бамперы совпадают с цветом края кузова во всех вариантах. Переключение палитры сохраняет город, паузу и текущий кадр анимации. Выбор сохраняется в браузере независимо от города.

Начальная палитра задаётся параметром `?palette=ocean`; без параметра используется сохранённый выбор или `brand`. Для прямого подключения есть `window.GVPTruck.setPalette('forest')` и `getPalette()`. Неизвестные значения возвращают `false`, сцена остаётся прежней. Для iframe отправьте сообщение после загрузки:

```js
frame.contentWindow.postMessage(
  { type: 'gvp-palette', palette: 'sunset' },
  window.location.origin
);
```

Цветовые наборы находятся в `palettes.css`; подключите его после `truck.css`. Для статической разметки достаточно `data-palette="ocean"` вместе с `data-theme="light"` или `data-theme="dark"` на `.gvp-truck`. В галерее общий переключатель синхронизирует палитру со всем брендбуком и скачиваемыми материалами. Выбор внутри iframe сообщает родителю событие `gvp-palette-change`; входящие сообщения не вызывают повторного события. Контраст белой надписи на борту составляет от 4,83:1 до 7,51:1 в зависимости от гаммы.

## Подключение через iframe

Сохраните структуру папок `brand`: компонент использует соседние `01-mascot`, `02-logos`, `03-icons` и `06-fonts`.

```html
<iframe
  src="brand/10-motion/truck.html?embed=1&theme=light&city=moskva&palette=brand"
  title="Фирменный грузовик Груз в пути"
  loading="lazy"
  style="display:block;width:100%;height:410px;border:0"
></iframe>
```

`theme=dark` задаёт тёмную тему при открытии. В режиме `embed=1` остаются выбор города и палитры, один грузовик и кнопка паузы. Для изменения темы без перезагрузки отправьте сообщение в уже загруженный iframe:

```js
frame.contentWindow.postMessage(
  { type: 'gvp-theme', theme: 'dark' },
  window.location.origin
);
```

Отправляйте сообщение также по событию `load` iframe, чтобы его начальная тема совпала с темой страницы. Обработчик принимает сообщения только от родительского окна и только два значения темы: `light` и `dark`. Выбранный город и состояние паузы при смене темы сохраняются.

## Подключение существующего выбора города

Значения `city` совпадают с исходным списком `<option>` пользователя: например, `moskva`, `sankt-peterburg`, `tyumen`. Начальный город задаётся параметром `?city=tyumen`. Без параметра восстанавливается последний выбор в этом браузере, а при первом открытии используется Москва. Недоступное локальное хранилище не мешает работе.

Если компонент находится в iframe, подключите существующий `<select>` сайта так:

```js
const citySelect = document.querySelector('#city');
const frame = document.querySelector('#delivery-truck');
function syncCity() {
  frame.contentWindow.postMessage(
    { type: 'gvp-city', city: citySelect.value },
    window.location.origin
  );
}
citySelect.addEventListener('change', syncCity);
frame.addEventListener('load', syncCity);
```

Пример рассчитан на iframe с того же домена. Если файл размещён на другом домене, укажите его точный origin вторым аргументом `postMessage`.

При прямом подключении разметки в тот же документ доступен `window.GVPTruck.setCity('tyumen')`; `getCity()` возвращает текущий ключ. Метод возвращает `false` для неизвестного города, не меняя сцену. Рисунки берутся только из фиксированного локального набора: пользовательские строки не становятся SVG. Изменение города обновляет фон сразу и сохраняет состояние паузы.

Для прямого подключения разметки скопируйте один `<article class="gvp-truck">` из HTML, при необходимости блок `.gvp-motion-controls`, и подключите `truck.css`, `palettes.css`, `city-landmarks.js`, затем `truck.js`; поправьте относительные адреса маскота, логотипа и шрифта при изменении расположения файлов. В CSS общая оболочка демо отделена комментарием от компонента.

## Поведение и доступность

Кнопка «Пауза» останавливает всю сцену, «Продолжить» возобновляет движение. При `prefers-reduced-motion: reduce` сцена автоматически становится статичной, а кнопка объясняет выбранный режим. Рисунок декоративный, скрыт от скринридера; название компонента и управление доступны с клавиатуры. Компонент не сообщает статус реального заказа и не обещает время доставки.

Проверено в Chromium: 17 разных геометрий и названий в двух темах; выбор через интерфейс, URL, API и сообщение родителя; игнорирование неизвестного города; сохранение паузы при смене города и темы. Проверена публичная сборка по пути проекта при ширине страницы 320, 390, 768, 1024 и 1440 px, высота iframe 410 px, отсутствие прокрутки и обрезанных элементов, уменьшение движения и загрузка всех локальных ресурсов.
